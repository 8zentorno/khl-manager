# KHL Manager — публикация на GitHub Pages и подключение к Telegram

## 1. Залить файлы
1. Создай репозиторий (например `khl-manager`), публичный.
2. Загрузи в корень репозитория **содержимое** папки `khl_manager_deploy` (не саму папку): `index.html`, `sw.js`, `pwa.js`, `manifest.webmanifest`, `.nojekyll`, папки `css`, `js`, `icons`.
   Файл `.nojekyll` скрытый: при загрузке через сайт GitHub проверь, что он попал в репозиторий (если нет, создай пустой файл с таким именем кнопкой Add file → Create new file).
3. Settings → Pages → Source: Deploy from a branch → Branch `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты игра откроется по адресу `https://<твой-логин>.github.io/<репозиторий>/`.

## 2. Подключить к боту
В @BotFather: `/newapp` (или `/mybots` → бот → Bot Settings → Menu Button → Configure menu button) и укажи адрес из шага 1. Адрес должен быть с HTTPS и вести на `index.html`.

## 3. Обновление версии
Заменяй файлы в репозитории новой сборкой. Версия кэша меняется внутри `sw.js`, поэтому тестеры получают обновление при следующем открытии (иногда после двух запусков).

## Сохранения
Игра хранит данные на устройстве и дублирует их в облако Telegram. Перенос между ПК и телефоном: «Сохранения» → «Скопировать код» / «Вставить код».
